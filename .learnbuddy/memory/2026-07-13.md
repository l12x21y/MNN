### GPU 探测结论 (test_mnn_gpu.py)
- backend=2 OpenCL → 伪GPU (被 MNN 静默回退 CPU)
- backend=4 Vulkan → **真 GPU, 可用** ✅
- backend=5 CUDA → 伪GPU
- backend=0 CPU → 可用
- 结论: 本机首选 backend=4 (Vulkan)。

### 关键结论
1. `demo.py` 当前 `USE_GPU=1` → `GAZEFOLLOWER_MNN_BACKEND=4` (Vulkan) 已是**真 GPU**,
   无需改动即可用 GPU。已用构造冒烟测试验证 `MGazeNet 使用后端 backend=4 (GPU)`。
2. **眨眼帧剔除 (`eye_blink_threshold`, 默认10) 只在 `CalibrationController.add_cali_feature`
   里用, 与 MNN 后端(GPU/CPU)完全解耦**。所以"用 GPU"不需要动眨眼剔除逻辑,
   二者可并存, 不存在二选一矛盾。
3. 视频流畅性由架构保证: 播放期零分配显示缓冲(rgb_buf 复用)+ 摄像头推理限速
   `process_fps=15Hz` 独立线程 + 播放期不做任何可视化(热力图全离线)。
