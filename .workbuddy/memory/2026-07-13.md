## 修复: demo.py 导入即崩溃 "Logger has not been initialized"
- 现象: 运行 `demo.py` 时在 `from gazefollower import GazeFollower` 阶段抛出
  `Exception: Logger has not been initialized. Please call Log.init() first.`
- 根因: `GazeFollower.__init__` 的原默认参数
  `gaze_estimator: GazeEstimator = MGazeNetGazeEstimator()` 会在**类定义(import)时**
  立即求值并构造估计器; 而我之前在 `MGazeNetGazeEstimator.__init__` 里加了
  `Log.i/Log.w` 调用。此时 `Log.init()`(在 `GazeFollower._create_session` 内)还没被
  调用, 于是崩溃。
- 修复: 把该默认参数改为 `None`, 在 `__init__` 内部、`self._create_session(...)`(它调用
  `Log.init()`)之后再做惰性构造:
  `self.gaze_estimator = gaze_estimator if gaze_estimator is not None else MGazeNetGazeEstimator()`
- 附带好处: 多个 GazeFollower 不再共享同一个估计器实例。
- 验证: `.venv` 下 `py_compile` 通过; `from gazefollower import GazeFollower` 不再在
  导入期崩溃(打印 import OK)。
